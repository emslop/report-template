# Шаблон доклада

Исходники трёх этапов: текст выступления, описание слайдов, презентация XeLaTeX/Beamer. PDF не собирается.

## Структура

```text
AGENTS.md                       Общие инструкции агенту
script/AGENTS.md                Требования к тексту выступления
slides/AGENTS.md                Требования к описанию слайдов
presentation/AGENTS.md          Требования к TeX-вёрстке
presentation/presentation.tex  Титульный и один содержательный слайд
presentation/images/           PNG-пример и его текстовое представление
presentation/tools/            Восстановление PNG без LaTeX
```

Используются `AGENTS.md`, а не `AGENT.md` или `SKILLS.md`: общие инструкции находятся в корне, инструкции этапов — в каталогах.

## Минимальный пример

— Тема: «Шаблон презентации».
— Студент: «Иванов Иван Иванович».
— Сохранена институциональная титульная компоновка [исходного presentation.tex](https://github.com/emslop/laser-welding-biotissues/blob/main/presentation.tex), шрифты и формат 16:9.
— Исходное тематическое содержание удалено.
— После титульного оставлен один содержательный слайд с PNG-схемой условной системы и таблицей назначения её компонентов.
— Рисунок и таблица подписаны; номера объектов начинаются заново на каждом слайде.
— Титульный учитывается в количестве без видимого номера, пример имеет номер `2/2`.
— Схема является условным учебным примером, а не результатом эксперимента.

## Работа

1. Задайте тему и объём доклада.
2. Подготовьте `script/script.md` по локальным инструкциям.
3. Подготовьте `slides/slides.md`, сохраняя заголовки и порядок.
4. Обновите `presentation/presentation.tex` по согласованному плану.
5. Сборку PDF разрешайте отдельно. Она не выполняется при настройке шаблона.

## PNG без сборки презентации

PNG хранится также в base64, поскольку используемый интерфейс загрузки передаёт текстовые файлы. Для восстановления из корня:

```sh
python3 presentation/tools/restore_example.py
```

Команда использует только стандартную библиотеку Python, не обращается к сети и не запускает LaTeX. Workflow `Initialize PNG example` выполняет только эту операцию и коммитит PNG. Если Actions отключены или запись запрещена настройками, выполните восстановление локально и добавьте PNG самостоятельно.

Для будущей вёрстки понадобятся XeLaTeX, пакеты из преамбулы, Liberation Sans и Liberation Mono. Компиляция не выполнялась; PDF и служебные файлы исключены через `.gitignore`.

## Статус GitHub Template repository

Содержимое шаблона и флаг GitHub `Template repository` — разные вещи. Доступный интерфейс записи файлов не меняет этот флаг. Включите **Settings → General → Template repository** или выполните в своём авторизованном GitHub CLI:

```sh
gh api --method PATCH repos/emslop/report-template -F is_template=true
```

Эта команда не запускается в workflow. Не сохраняйте токены в репозитории.
